# Historical security badge solution

This solution's event generator uses `WindowsAzure.ServiceBus`, which retired for Event Hubs on September 30, 2026. The source is retained for reference, not current deployment guidance. Migrate its producer using the [Event Hubs migration guide](https://github.com/Azure/azure-sdk-for-net/blob/main/sdk/eventhub/Azure.Messaging.EventHubs/MigrationGuide_WindowsAzureServiceBus.md) before reusing it.
